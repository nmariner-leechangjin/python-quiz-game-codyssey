# 파이썬 콘솔 퀴즈 게임

Codyssey 「컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기」 미션 프로젝트입니다. 이 README는 과제의 **최종 결과물 1 → 2 → 3번 순서**에 따라 작성했습니다. 현재는 저장소 초기 설정 단계이므로 구현 전 기능을 완료로 표시하지 않습니다.

## 1. 동작하는 퀴즈 게임

### 프로젝트 개요

Python으로 터미널에서 실행하는 퀴즈 게임을 만듭니다. 메뉴에서 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 최고 점수 확인, 종료를 선택할 수 있게 할 예정입니다.

### 퀴즈 주제와 선정 이유

주제는 기본 퀴즈를 작성하기 전에 결정합니다. 선정 이유와 직접 만든 문제 5개 이상을 이곳에 기록할 예정입니다.

### 실행 방법

프로그램 진입점과 실행 명령은 구현 후 실제 실행을 확인하여 기록합니다. **현재 실행 가능한 퀴즈 게임은 없습니다.**

### 기능 목록과 현재 상태

| 기능 | 현재 상태 |
| --- | --- |
| 번호 선택 메뉴와 종료 | 구현 예정 |
| 퀴즈 풀기와 결과 표시 | 구현 예정 |
| 새 퀴즈 등록 | 구현 예정 |
| 저장된 퀴즈 목록 | 구현 예정 |

| 잘못된 입력, `Ctrl+C`, EOF 처리 | 구현 예정 |
| 종료 후 재실행 시 퀴즈와 최고 점수 유지 | 구현 예정 |

## 2. 코드 구조

`Quiz` 클래스는 문제, 4개 선택지, 정답과 정답 확인을 담당하고, `QuizGame` 클래스는 메뉴와 게임 진행을 담당하도록 설계할 예정입니다. 입력 처리와 JSON 저장·불러오기는 기능별 메서드로 분리합니다.

### 파일 구조

```text
.
├── .gitignore   # 로컬 데이터와 Python 생성 파일 제외
└── README.md    # 프로젝트 안내와 진행 상태
```

Python 소스 파일과 테스트 파일은 구현하면서 파일 구조에 추가합니다.

### 데이터 파일: `state.json`

프로그램 실행 중 프로젝트 루트에 UTF-8 JSON 파일을 생성할 예정입니다. 이 파일에는 `quizzes`(문제·선택지·정답 목록)와 `best_score`(최고 점수)를 저장합니다. 파일이 없으면 기본 퀴즈를 사용하고, 손상되면 안내 후 기본 데이터로 복구하도록 구현할 예정입니다. 개인 실행 데이터이므로 `state.json`은 Git 추적에서 제외합니다.
