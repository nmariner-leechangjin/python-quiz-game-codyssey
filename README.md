# 파이썬 콘솔 퀴즈 게임

Codyssey 「컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기」 미션을 위한 프로젝트입니다.

현재는 로컬 Git 저장소의 초기 설정 단계입니다. 퀴즈 게임 구현과 실행 방법은 이후 기능별 작업에 맞춰 기록합니다.

## 개발 예정 기능

- 메뉴에서 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 최고 점수 확인, 종료 선택
- `Quiz`와 `QuizGame` 클래스로 역할 분리
- 프로젝트 루트의 UTF-8 `state.json`에 추가한 퀴즈와 최고 점수 저장

## 퀴즈 주제

주제와 선정 이유는 기본 퀴즈를 작성할 때 기록합니다.

## 실행 방법

프로그램 구현 후 실행 명령을 기록합니다.

## 파일 구조

- `README.md`: 프로젝트와 진행 상태 안내
- `.gitignore`: 로컬 실행 파일과 비밀 정보의 Git 추적 제외
- `state.json`: 실행 중 생성될 로컬 퀴즈 및 점수 데이터

## 데이터 파일

`state.json`은 프로젝트 루트에 생성될 예정입니다. 퀴즈 목록과 최고 점수를 저장하며, 구체적인 JSON 스키마는 저장 기능 구현 시 기록합니다. 개인 실행 데이터이므로 Git 추적에서 제외합니다.
